# Finora frontend

Nepal-focused personal finance UI. This folder is the React + Vite application.

## Stack

- React 19 + Vite
- Tailwind CSS 4
- React Router
- Lucide icons
- Recharts

## Scripts

```bash
npm install
npm run dev
npm run build
npm run lint
```

Auth, transactions, accounts, budgets, and goals currently use mock data and `localStorage` through `src/config/services.js`. Those functions are the future REST API boundary.
